# Guia de Contribuição

Agradecemos por considerar contribuir com o Sistema de OP! 

## Como Contribuir

### Reportar Bugs

Antes de criar um relatório de bug, verifique se o problema não foi reportado. Se encontrar um bug:

1. **Use um título descritivo** para identificar o problema
2. **Descreva os passos exatos** que reproduzem o problema
3. **Forneça exemplos específicos** para demonstrar os passos
4. **Descreva o comportamento observado** e qual era o esperado
5. **Inclua screenshots e GIFs** se possível

### Sugerir Melhorias

As sugestões de funcionalidades são bem-vindas! Quando criar uma sugestão:

1. **Use um título descritivo**
2. **Forneça uma descrição detalhada**
3. **Liste exemplos de como seria usado**
4. **Liste versoes similares de outras aplicações**

### Pull Requests

1. Fork o repositório
2. Crie uma branch para sua feature (`git checkout -b feature/MinhaFeature`)
3. Commit suas mudanças(`git commit -m 'Add MinhaFeature'`)
4. Push para a branch (`git push origin feature/MinhaFeature`)
5. Abra um Pull Request

## Checklist de PR

- [ ] Titulo descritivo
- [ ] Descrição das mudanças
- [ ] Referência a issues relacionadas
- [ ] Screenshots/GIFs se alterou UI
- [ ] Código segue o style guide
- [ ] Sem console.logs desnecessários
- [ ] Comentários adicionados para seções complexas
- [ ] Documentação atualizada

## Code Style

- Use 2 espaços para indentação
- Use `const` por padrão
- Use nomes descritivos para variáveis
- Adicione comentarios para lógica complexa
- Mantenha linhas com máximo 100 caracteres

## Processo de Revisão

1. Uma ou mais pessoas vão revisar seu PR
2. Mudanças podem ser solicitadas
3. Uma vez aprovado, seu PR será merged
4. Parabéns! 🎉

## Comunidade

- Seja respeitoso e construtivo
- Leia antes de comentar
- Não faça comentários ofensivos
- Estamos todos aqui para melhorar o projeto
